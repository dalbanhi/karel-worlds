## 🌟 Overview

KarelWorlds is all about making computer science fun and accessible for everyone, especially beginners! Inspired by [Scratch](https://scratch.mit.edu/) and the classic [Karel programming language](<https://en.wikipedia.org/wiki/Karel_(programming_language)>), this platform was created by a [developer and computer science teacher](https://david-alban.com/) who wanted to share the excitement and magic of coding in a way that's fun and accessible.

With [Blockly](https://g.co/dev/blockly), you can drag and drop blocks of code to help Karel the Robot solve fun puzzles. Blockly is a tool from Google that makes block-based programming simple and beginner-friendly.

If you're curious to learn more about the KarelWorlds project, you can dive into the [technical details here at this write up](https://david-alban.com/projects/karelWorlds). You can also find the [source code for this project here](https://github.com/dalbanhi/karel-worlds). If you have any questions, feel free to [reach out to us here](https://karelworlds.org/contact).

## ✨ Features

- 🎮 **Interactive Puzzle Creation** – Build custom Karel worlds with separate start and goal states to practice problem-solving.
- 🧩 **Block-Based Coding with Blockly** – Drag-and-drop coding makes learning programming intuitive for beginners.
- 💻 **Real-Time JavaScript Translation** – Instantly see your block-based solutions converted to actual JavaScript code.
- 🌐 **Share & Solve Puzzles** – Share your creations with friends or try solving puzzles made by others.
- 🎨 **Customizable Sprites** – Personalize Karel and beepers for a creative and social coding experience.
- 📱 **Responsive & Cross-Platform** – Works seamlessly on desktops, tablets, and mobile devices.

## 🎯 Quick Start

Get up and running with KarelWorlds in just a few steps!

### Prerequisites

Make sure you have the following installed:

- Node.js (v14 or higher)
- npm
- Git

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/dalbanhi/karel-worlds.git

   cd karel-worlds
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Set up environment variables**

   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

4. **Run the application**
   ```bash
   npm start
   ```
5. **Open your browser**

   Navigate to http://localhost:3000 to explore KarelWorlds!

## 📊 Roadmap

### Short Term Goals

- [ ] 🧩 **Introductory Puzzles** – Build tutorial puzzles to help new users get started quickly.
- [ ] 🛠 **Ease-of-Use Improvements** – Refine the puzzle creation interface for smoother user experience.

### Medium Term Goals

- [ ] 🔁 **State Management Refactor** – Use Redux for cleaner, more maintainable state handling.
- [ ] 🚧 **Add Walls & Function Definitions** – Make puzzles more challenging and allow users to define reusable functions.
- [ ] 🧪 **Beta Testing with Students** – Gather feedback to refine the platform and improve engagement.

### Long Term Goals

- [ ] 🏫 **Teacher & Classroom Accounts**– Enable educators to manage classes, assign puzzles, and track progress.
- [ ] 🔒 **Safety & Security Enhancements** – Ensure the platform is safe, secure, and appropriate for all users.
- [ ] 🏆 **Achievements & Badges** – Reward users for completing puzzles and learning milestones.

See the [open issues](https://github.com/dalbanhi/karel-worlds/issues) for a full list of proposed features and known issues.
